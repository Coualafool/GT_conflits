Fraction A — Frise « lecture par paliers »

Chaque événement porte un niveau de détail défini dans les données (majeur / standard / détail). Le zoom révèle les paliers : dézoomé → les ères seules ; zoomé → tous les événements et les mois. Zéro dépendance, fonctionne hors ligne en file://.

Comment lire la frise

  • Molette ou pincement = zoom
  • Glisser = naviguer
  • Double-clic = zoom au point
  • Clic sur un point = détail
  • Clic sur une ère = zoom sur l’ère
  • Bas de l’écran : vue d’ensemble cliquable
  • ←→ naviguer · +− zoom · 0 tout · ? aide · Échap fermer
événement majeur standard détail couleur du point = ère
