Variante IL'Hélice des récits — la tresse, en vivant

Comme une molécule de vie : le temps est l'axe, chaque récit est un brin de la triple hélice — aucun brin n'est au centre. Les marches relient les versions d'un même fait ; dorées, quand les noms divergent. Taille des cellules = poids dans le récit.

Comment lire l'hélice

Le temps est l'axe central. Chaque récit est un brin enroulé autour de cet axe — comme le collagène, trois brins, aucun au centre. Une cellule n'existe que sur les brins qui racontent ce fait ; les marches relient entre elles les versions d'un même fait, comme les barreaux d'une molécule.
