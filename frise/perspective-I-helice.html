Variante IL'Hélice des récits — la tresse déroulée

Le temps coule de haut en bas ; chaque récit est un brin tressé autour de lui — aucun brin au centre. Le lien qui traverse la tresse relie les versions d'un même fait, doré quand les récits ne le nomment pas pareil. Un cercle pointillé sur un brin : un fait que ce récit se tait.

Comment lire la tresse

Faites défiler : vous remontez et descendez le temps. Les trois brins se croisent comme les fils d'une tresse — un fait apparaît sur chaque brin qui le raconte. Le trait qui traverse la tresse à la hauteur d'un fait relie ses versions ; doré, quand les récits ne lui donnent pas le même nom ; les cercles pointillés, quand un récit se tait. Cliquez une carte : les versions s'affichent côte à côte.

Flèches ↑↓ d'un fait à l'autre · Entrée ouvrir · Échap fermer · N maintenant · ? aide · Tab parcourt les cartes dans l'ordre du temps.
